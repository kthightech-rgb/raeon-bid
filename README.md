# 입찰공고 도우미 래온

공동주택 관리소장을 위한 주택관리업자·공사·용역 사업자 선정 입찰공고문 작성 및 K-apt 입찰계획서 등록 도우미입니다.

- 바로 쓰기: https://kthightech-rgb.github.io/raeon-bid/
- 7단계: ① 단지·연결 ② 입찰 유형 판정 ③ 입찰 조건(실시간 법령 검증) ④ 일정(공휴일 반영) ⑤ 공고문(한글 HWPX·PDF) ⑥ 자가진단(myapt 21문항·필수항목) ⑦ K-apt 입찰계획서 입력표
- 기준: 「주택관리업자 및 사업자 선정지침」 국토교통부고시 제2024-196호, 「공동주택관리법」·시행령 2026.7.1. 시행본, 경기도 준칙 제23차·서울시 준칙 제19차 세부평가표
- 입력값은 사용하는 브라우저에만 저장되며 서버로 보내지 않습니다. 결과는 참고용이며 최종 확인 책임은 발주처에 있습니다.

## 이용 안내

- 이 앱은 래온(來On)이 만든 무료 도구이며, 국토교통부·K-apt·중앙공동주택관리지원센터·주택관리사협회의 공식 서비스가 아닙니다.
- 결과물은 작성 보조용 참고자료입니다. 법령 적용과 최종 내용의 확인·책임은 사용하는 관리주체에게 있습니다.
- 입력한 내용·파일·인증키는 이 브라우저에만 저장되며 제작자에게 전송되지 않습니다. 화면 구성용 라이브러리를 외부(jsDelivr)에서 불러오므로 접속 기록은 GitHub와 해당 CDN에 남을 수 있습니다.
